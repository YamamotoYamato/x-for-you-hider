# Hide For you on X

A Chrome extension that hides the For you tab on X (formerly Twitter) and automatically switches to Following whenever For you is selected. If Following is already selected, it leaves it unchanged. It continues working when X rerenders its tabs during navigation.

## Installation

1. Open `chrome://extensions` in Chrome.
2. Turn on Developer mode.
3. Select **Load unpacked** and choose this repository folder.
4. Reload X.

If the extension is already installed, reload it on `chrome://extensions`, then reload the X page.

The extension runs on `x.com` and `twitter.com`. It requests no permissions and makes no network requests.
